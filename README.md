# 谁的「上岸」才算数？｜提交版

从《升本后醒来》出发，拆解学历符号、歌曲中的幽默与网友的再创作。

## 本地打开

解压后，用浏览器打开 `index.html`。网站使用原生 HTML、CSS 和 JavaScript，背景视频随包提供，可静音循环播放。

## 发布到 GitHub Pages

1. 把解压后的文件和文件夹上传到仓库根目录，确保 `index.html`、`assets/` 和 `.nojekyll` 都在根目录。
2. 在仓库的 **Settings → Pages** 中，选择 **Deploy from a branch**，选中存放这些文件的分支及 **/(root)**，保存。

[GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
